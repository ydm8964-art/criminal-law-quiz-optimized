# 刑法条文练习

一个可直接部署到 GitHub Pages 的纯静态刑法条文练习网站。

## 功能特性

### 题型设计

- **选择题**：条文原文挖空关键词，从4个选项中选择正确答案（包含易混淆干扰项）
- **判断题**：给出可能正确或错误的条文表述，判断对错（2选1）
- **填空题**：条文原文留空，手动输入关键词
- **改错题**：给出错误表述，找出并更正错误关键词

### 核心功能

- 覆盖《中华人民共和国刑法》505条条文（2024年修正版）
- 支持章节筛选、全文搜索和条文号快速跳转
- 自动记录学习进度、错题、正确率和连续答对次数
- 错题本支持按题型筛选
- 支持亮色/暗色主题切换
- 完整的移动端适配和触摸手势支持
- 支持键盘快捷键和 PWA 安装体验

### 快捷键

- `← / →` 切换条文
- `Enter` 提交答案
- `H` 显示/隐藏提示

### 移动端

- 左右滑动快速切换条文
- 底部快捷导航栏
- 可添加到主屏幕作为独立应用

## 部署

本项目无需构建，直接使用 GitHub Pages 发布仓库根目录即可。

推荐配置：

- Branch: `gh-pages`
- Folder: `/ (root)`

## 技术栈

纯原生 HTML + CSS + JavaScript，无任何依赖，支持离线使用。
